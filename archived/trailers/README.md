# 🎬 Archived for trailers – starý vzhled na natáčení

Když potřebuješ natočit starší verzi (trailer, srovnání „dřív a teď“), nainstaluj APK z `release/`:
stará verze se instaluje vedle nové a světy přeneseš přes Export / Import.

| Co natočit | APK | Kde ve hře |
|---|---|---|
| Starý tvůrce doplňků (Módy a balíčky, JSON editor) | `release/VoxelCraft-2.6.0.apk` | Menu > Módy a balíčky |
| Staré textury (vajíčka s tečkami, maso, šíp, provázek, ingoty, hardiová ruda) | `release/VoxelCraft-2.6.0.apk` | Kreativ |
| Staré zarážedlo na koleji | `release/VoxelCraft-2.6.0.apk` | Kreativ > Železnice |
| Kabina lokomotivy metra s dveřmi | `release/VoxelCraft-2.6.0.apk` | Kreativ > Železnice |
| Starší verze | `release/VoxelCraft-<verze>.apk` | — |

Snímky starého UI jsou v `archived/ui_2.6.0/`.
